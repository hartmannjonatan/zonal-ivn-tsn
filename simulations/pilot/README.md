# Exploratory pilots

This directory contains isolated studies that inform, but do not replace, the P1 experiments. Each pilot retains its own protocol, configuration, results, and limitations.

- [C4 CBS/TAS study — consolidated report](README_C4_CBS_TAS.md): history, corrections, final reconciled evidence, and prospective C4 recommendation.
- [Reclassification pilot results](reclassification/results/analysis_corrected.md): historical pilot that informed the common PCP/TC mapping. Its results are excluded from official campaign aggregates.

The C4 exploration is closed. Its recommended absolute profile is not yet an official frozen C4 treatment; a versioned P1 addendum is required before the official C4 campaign. Do not infer execution status from this index; use the relevant pilot checkpoint and ledger.
